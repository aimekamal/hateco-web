# hateco-web
Hateco website redesign demo


## Features
- Light / dark theme toggle (remembers choice, follows system by default)
- English / Arabic (RTL) language button
- Responsive layout, dropdown + mobile menu, brand carousel, tire finder, scroll animations
- Black / white / beige / orange palette

## Files
- `index.html` – markup and content
- `style.css` – styles and theme variables
- `script.js` – interactions and Arabic translations

## Run
Open `index.html` in a browser, or host free with GitHub Pages
(Settings → Pages → Deploy from branch → `main` / root).

Content source: https://www.hateco.com.lb
